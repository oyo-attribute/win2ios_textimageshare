# Win2ios Clipboard Sync Server

Windows PCとiOSデバイス間で、テキストや画像をシームレスに共有（クリップボード同期）するためのローカルサーバーアプリケーションです。
Windowsのタスクトレイに常駐し、同一Wi-Fiネットワーク上のiOSからのデータ送受信をバックグラウンドで処理します。

## ✨ 主な機能
* **テキスト・画像の双方向共有:** iOSからWindowsへ、WindowsからiOSへ、クリップボードの内容を送信・取得できます。
* **HEIC形式の画像対応:** iOS特有のHEIC形式の画像を受信した場合でも、自動的にPNGに変換してWindowsのクリップボードにコピーします。
* **リッチテキスト(RTF)のクリーンアップ:** 書式付きテキストを受信した際、プレーンテキストに変換してコピーします。
* **タスクトレイ常駐:** コマンドプロンプト画面を出さずにバックグラウンドで静かに動作します。
* **ブラウザモニタリング機能:** 現在サーバーが保持しているiOS/Windowsのデータを、Webブラウザ ( `http://localhost:8000` ) から確認できます。
